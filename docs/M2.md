# M2 incremental authoring and cartography

**Stage:** incremental M2 slice. GitHub Actions PR verification passed: 31 unit tests, 15 browser tests, zero Svelte/TypeScript errors, and successful production build. Further engineering/geology work remains. No external models, images, fonts, servers, datasets or third-party map tiles.

## Implemented in this branch

- **Standalone New World:** author names a world, chooses a seed and radius. New worlds use the `m2-seeded-v1` generator with seed-varied fictional continental and oceanic relief. Original Aurelia files retain their exact `m0-sample-v1` raster and sample place names; this generator is not tectonics or climate simulation.
- **Geodesic terrain editing:** smooth falloff spherical-radius brushes add/subtract elevation using geographic anchors. They cross the antimeridian, remain spherical at poles, save in the world file, and regenerate deterministically on top of the selected base world.
- **Authorship and conflict safety:** terrain edits are editable history, up to 256 strokes, with an explicit clear last operation, global Undo and local recovery. Brushes reject overlap with locked landmarks.
- **Portable v2 projects:** newly created and sculpted projects write version 2 with a validated `terrain_strokes` list. Older v0/v1 sample projects remain loadable (v0 still migrates as before). Older builds should reject version 2 rather than silently dropping authored terrain.
- **Cross-section:** the existing Measure distance tool includes a spherical geodesic elevation profile of the actual edited raster (sea level drawn separately).
- **Physical relief globe:** an adaptive-to-planet-radius bounded vertical exaggeration deforms the sphere's geometry. The actual elevation raster and inspector values remain unchanged.
- **Original atlas styling:** both Natural Atlas and Survey Sheet palettes render from the shared elevation raster with fine bathymetric/land contours and lightweight hillshade. A parchment/editorial responsive workspace follows the visual inspirations without copying external imagery or installing remote dependencies.

## Controls

1. **+ Create new world** opens a local standalone world form in Places. Export your current world first; switching worlds records an undo/recovery snapshot.
2. Select **Sculpt terrain** in the atlas toolbar to paint with clicks. Choose radius (1–2,500 km) and signed elevation change (±3,000 m, nonzero) in the Terrain sculpting inspector. Drag still pans.
3. Alternately leave sculpt mode off and choose **Apply at selection** for a single controlled geographic stroke.
4. **Remove last** removes the most recent terrain edit; **Undo last edit** restores the previous project snapshot. Lock an important landmark to prevent paint overlapping it.
5. Choose **Style → Natural atlas / Survey sheet** to switch the original two cartographic palettes. This is purely display styling.
6. Use **Measure distance → Set start at selection**, then inspect a second location to see the seabed/terrain elevation profile and spherical distance.
7. Export a `.orbis.json` backup and reimport it to verify all authored strokes remain.

## Format compatibility and limitations

- `format: "orbis-project"`, `version: 2`, `planet.algorithm_version: "m2-seeded-v1"` or `"m0-sample-v1"`, and ordered `terrain_strokes` entries `{ id, lat_deg, lon_deg, radius_km, delta_m }`.
- For v1 fixtures the original terrain generation is unchanged. v0 legacy import still retains the old migration payload.
- Project import size stays **2 MB**, existing landmark/draft caps remain, and stroke cap is 256.
- Terrain deformation modifies the base elevation raster after seed generation. **Brush strokes are replayed**, not stored as a 720×361 dense raster. This is ideal for early authoring but will need a patch-tile/binary persistence format and region LOD for thousands of fine details.
- Current sculpting applies one stroke per click (not continuous pressure-sensitive brush painting). Coarse atlas raster resolution still limits fine coastal detail.
- The simplified seeded generator is illustrative, not geophysically validated. Watersheds, tectonics, individual water bodies and underground cave topology remain out of scope here.
- Globe vertical exaggeration is **visual only**, bounded at ±3% radius to avoid unrealistic deformation on very small planets. Profile and inspector always report signed physical elevations.
- Rendering and generation still run on the main thread; later work should profile and move heavy generation to cancellable workers. Do not imply low-end device performance from desktop benchmarks.
- This does **not** integrate with Arline Studio.

## Design research

- swisstopo national maps: detailed legible relief and careful cartographic hierarchy. https://www.swisstopo.admin.ch/en/national-map-1-10000
- MapTiler hillshade and color relief: differential bathymetry/land palettes and simulated northwest sun. https://docs.maptiler.com/guides/map-design/terrain/hillshading/
- Felt interface: map-centric toolbar, contextual inspector and legend rather than disconnected dashboard tiles. https://help.felt.com/getting-started/tour-the-interface

These are conceptual references, not copied assets or source code.
